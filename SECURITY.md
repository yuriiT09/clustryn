# Security

Clustryn is currently an experimental educational project and is not intended for production use.

Do not use Clustryn to run untrusted workloads or store sensitive production data.

## Reporting a Security Issue

If you discover a security vulnerability, please do not publish sensitive exploit details in a public GitHub Issue.

Instead, contact the project maintainer privately and include:

- A description of the vulnerability
- Steps to reproduce it
- The affected component
- The potential impact

Security issues will be investigated and documented appropriately.
