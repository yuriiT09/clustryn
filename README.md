# Clustryn

Clustryn is an experimental fault-tolerant distributed computing platform.

The goal is to build a system capable of scheduling workloads across multiple nodes, detecting failures, and automatically recovering applications.

## Status

🚧 Active development

Current milestone: **Cluster Foundation**

## Long-term Goals

- Multi-node cluster
- Workload scheduling
- Automatic recovery
- Service discovery
- Load balancing
- Distributed storage
- Distributed key-value database
- Consensus
- Observability
- Chaos testing
